# Jam

![Jam](docs/brand/logo.png)

**Exploring ownership of real-world assets through a modern investment interface.**

Jam is a project focused on the experience of discovering tokenized real-world
assets and viewing an investment portfolio. Its application work combines
Next.js, Solana wallet integration and authentication.

## Project status

Application development is ongoing. This public repository is the project
showcase; the application source, operational configuration and development
history remain private. This page does not announce an investment offering or
claim that asset issuance, custody or transactions are available.

## Areas of work

- Asset discovery and portfolio presentation.
- Wallet and account onboarding.
- Connecting the interface to backend services.

The existing Jam logo is reused here to keep the project identity consistent.
